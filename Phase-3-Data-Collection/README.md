# Phase 3 — Data Collection & Data Sourcing

## 🎯 Objective
Understand how real-world data is collected, accessed, and stored from multiple sources such as databases, APIs, and web platforms.  
This phase focuses on acquiring raw data before analysis and modeling.

## 🧩 Topics Covered

### 1. SQL & Databases
- Basic SQL queries (`SELECT`, `WHERE`, `ORDER BY`)
- Aggregation (`GROUP BY`, `COUNT`, `SUM`, `AVG`)
- Joins (`INNER`, `LEFT`, `RIGHT`)
- Database design fundamentals
- Understanding structured data storage
- Connecting Python with SQL (integration practice)

### 2. APIs (Application Programming Interfaces)
- Understanding how APIs work
- Making HTTP requests using Python
- Handling JSON responses
- Working with public APIs (weather, finance, etc.)
- Collecting real-time structured data

### 3. Web Scraping
- Understanding HTML structure
- Extracting data from web pages
- Using libraries such as BeautifulSoup / Requests
- Handling scraped data responsibly
- Storing extracted data for analysis

## 📈 Learning Outcomes
By completing this phase, I am able to:
- Collect structured data from relational databases
- Fetch live data from APIs using Python
- Extract useful information from websites
- Store and prepare raw data for further analysis
- Understand the complete data acquisition pipeline

## 🏗️ Practical Work
- Writing SQL queries for real datasets
- Fetching live API data and processing JSON responses
- Building simple web scrapers
- Storing collected data into CSV or JSON format
- Mini end-to-end data collection exercises

> 📌 This phase represents hands-on practice in real-world data sourcing and is a foundational step before data visualization and machine learning.
