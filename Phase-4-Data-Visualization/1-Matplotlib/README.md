##  When to Use Each Plot?

| Plot Type | When to Use? |
|---|---| 
| `Line Plot` | Show trends over time or continuous data |
| `Bar Chart` | Compare categories or discrete groups |
| `Scatter Plot` | Show relationship between two numerical variables |
| `Pie Chart` | Display proportion or percentage distribution |
| `Histogram` | Analyze data distribution and frequency |
| `Box Plot` | Detect outliers and summarize statistics |
| `Stack Plot` | Show cumulative contribution of multiple components over time |
| `Subplots` | Compare multiple plots in one figure |
