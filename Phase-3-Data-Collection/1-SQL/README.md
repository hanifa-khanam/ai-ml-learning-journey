##  Types of SQL Queries

| Type | Full Form | Purpose | Common Commands |
|------|-----------|----------|-----------------|
| DDL | Data Definition Language | Defines or modifies database structure | `CREATE`, `ALTER`, `DROP`, `TRUNCATE` |
| DML | Data Manipulation Language | Modifies data inside tables | `INSERT`, `UPDATE`, `DELETE` |
| DQL | Data Query Language | Retrieves data from database | `SELECT` |
| DCL | Data Control Language | Controls user permissions | `GRANT`, `REVOKE` |
| TCL | Transaction Control Language | Manages transactions and data consistency | `COMMIT`, `ROLLBACK`, `SAVEPOINT` |
