# Personal Expense Tracker

A Python-based **Personal Expense Tracker** to help users manage and monitor their income and expenses.  
This project uses **Object-Oriented Programming (OOP)** and **JSON & CSV file handling** for persistent data storage.

---

## Features

- Add, update, and delete transactions
- View all transactions in a readable format
- View a summary of total income, total expenses, balance, and category-wise totals
- Save transactions to a file (`data.json & data.csv`) for persistent storage
- Load previously saved transactions automatically
- Logging of actions for better tracking and debugging
- View `Pie Chart for Expense Distribution`, `Bar Chart for Expenses Category`, and `Plot Chart for Monthly Expense Trend`
